# Deadline-reach reward variant (not ASAP)

Status: inactive comparison experiment, not the current main version. The user
chose to retain the original ASAP-trained Transformer after this run degraded.
Models, logs and curves are preserved; no additional training is scheduled.

This folder is the separate gamma=1 deadline-reach experiment.
Entry: `train.py`; reward: `reward.py`; checks: `test_protocol.py`.
The Transformer architecture and PPO engine are shared with the sibling
`episode_transformer_bc` folder, but this experiment's configuration, reward
implementation, and output are kept here. Historical models/logs are unchanged.
The seed-0 gamma=1 run completed 800,027 steps (800,000-step budget, finishing
the current PPO update). Output: `runs/seed0_80w/`; console:
`runs/seed0_80w.console.log`. BC decayed to zero at 600,000 steps.
The final episode-3 six-case mean is 0: open cases succeed, all closed cases
time out. The learning curve is generated by `plot_returns.py` from actual
evaluations, without smoothing, under the run's `plots/` folder.

The new entry defaults to gamma=1 for both PPO targets and episode returns:
there is no temporal discount. Every action still initially costs d=0.01.
At the true episode ending (success or timeout), refund d*N, including the
final action's cost. The success discount compensation is zero at gamma=1.

Danger, collision, and timeout penalties are not refunded or discounted:
first danger entry -0.2 (once per episode), each wall/closed-gate collision
-0.05, timeout -1. Thus the episode return is

    G = I_success - 0.2*I_danger - 0.05*N_collisions - I_timeout.

Safe success has return 1 at every feasible arrival time. Danger success
without collisions has return 0.8. Timeout without danger/collisions has
return -1, independent of the deadline. Refund state resets each episode;
policy h is still inherited across all three episodes of a trial.

The six BC trial returns (episodes 1, 2, 3) are:

- Open D=15/17/25: (1, 1, 1) for each deadline.
- Closed D=15: (-1, -1, -1).
- Closed D=17: (-1, 0.8, 0.8).
- Closed D=25: (1, 1, 1).

Discounted and undiscounted logged returns coincide at gamma=1. Both are
retained for auditing. These rewards differ from the original training;
do not treat the old and new curves as using an identical reward definition.

## Optional gamma override

An explicit `--gamma` remains supported. If gamma<1 is intentionally selected,
the general terminal-refund implementation uses

    F_N = d * sum(t=0..N−1) gamma^t / gamma^(N−1).

The payment is itself discounted, so its discounted contribution exactly cancels
all step costs, including the cost of the final action. A plain refund of d*N
would not cancel the discounted deductions when gamma<1.

Also, if successful, supplement the original +1 goal bonus by:

    C_N = 1/gamma^(N−1) − 1.

This is necessary: refunding step costs alone would still favor earlier arrival
because the original terminal +1 is discounted. Safe successful episodes now
have discounted return exactly 1 at any feasible arrival time before or at D.

All other components retain their original emitted amounts and standard gamma
discount: first danger entry −0.2 (once per episode), each wall/closed-gate collision
−0.05, timeout −1. There is no refund of these costs. After compensation:

    G_gamma = I_success
              − 0.2 * gamma^(danger_step−1) * I_danger
              − 0.05 * sum(collision steps j) gamma^(j−1)
              − gamma^(N−1) * I_timeout.

With this explicit gamma<1 override, danger/collision/timeout penalties retain
their ordinary discounts; full time-invariance of those costs is not claimed.

When gamma<1, because terminal compensation is gamma-aware, the raw sum is not
the metric to compare arrival times. This variant logs and evaluates discounted
return as its main return, and retains `undiscounted_return` for auditing. Do not
overlay it with old undiscounted-return curves as if the reward metric were equal.
