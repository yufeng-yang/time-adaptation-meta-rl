## 布局

- 桌面 0.9 × 0.9 米，高 0.8 米；机械臂 Panda，20 Hz 控制。
- 任务原点固定为桌面中心 `(0, 0, 0.8)`，不是机器人基座坐标原点。
- 绿色浅盘位于任务原点；夹爪初始位姿在其正上方 0.12 米处。
- S（金色）固定在半径 0.18 米、靠机械臂的一侧。
- A/B/C/D（相同蓝色）在半径 0.36 米的外圈随机生成，共四个；加上 S 总计五球。
- 为避开当前机械臂无法可靠到达的角度，外圈在 80–145°、215–280° 两段
  圆弧上按弧长均匀采样，球心最小间距为 0.10 米；不再要求左右镜像摆放。
- 圆周和全部球都位于桌面范围内。
- 初始化时仅求解一次出生位姿的逆运动学并对齐控制器，不执行运动轨迹或训练。
- 五个球半径均为 0.025 米，密度和摩擦参数一致；外圈球不带价值外观标签。
- 圆周虚线只用于显示，无碰撞；浅盘底和盘沿具有真实碰撞。
- 球是自由物理对象，没有焊接到夹爪或固定在桌面。
- 默认每次运行生成新布局，每次 reset 重新采样四个外圈球；S 保持不变。
  使用 `--seed 0` 可复现运行时的布局采样序列。未来接入三局 trial 时，
  应改成每个 trial 只采样一次，三局共享布局。

布局参数集中在 `radial_layout.py` 的 `RadialLayout` 中，两种环境共享该参数。
当前 MuJoCo 场景只有物理场景和位置观测，奖励恒为 0；底层策略尚未训练。
另有 [上层可行性实验](high_level/README.md)：用计时的理想执行器实现隐藏价值、
接触揭示、单球投放终止、deadline 与三局 trial，并训练 Transformer + 跨局 GRU。

等半径只消除四个外圈球的平面几何距离差异，不能保证关节运动、抓取成功率
和控制步数相同。正式实验前需要用同一冻结底层实测完整取放与换目标耗时；
上层抽象环境按自身耗时标定采用 30/65/150，真实控制器接入后需要重新确定预算。
